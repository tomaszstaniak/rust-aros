# signal-hook-registry 1.4.6 on AROS ABIv1

Verify the crates.io archive against the SHA-256 in the patch header.
Extract into a disposable directory, apply the files in series with
`git apply`, and select the extracted crate through Cargo's
`[patch.crates-io]` for version 1.4.6. Use the dual libc generated by
tools/libc-dual.py from this repository. The patch uses the ABIv1
sigaction setter and existing handler slot in libc-aros.

For a smoke test, use probe.rs as a binary crate's main and select the
patched registry and generated libc with the ABIv1 target configuration.
The program prints SIGNAL_REGISTRY_OK after dispatch, unregister and
restoration of the original SIGUSR2 action. The native check exercises a
single task. Cross-task delivery and child reaping need separate tests.
The siginfo registration APIs return Unsupported on AROS ABIv1.

Keep this patch local while it uses our libc-aros setter. A general
upstream proposal would require an agreed public libc interface.
